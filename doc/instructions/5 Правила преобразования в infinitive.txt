Модуль `Infinitive` (инфинитив)

Исходя из базовых правил образования формы прошедшего времени в английском языке,
в программе реализованы правила, обеспечивающие обратное преобразование (удаление) окончания -ed
у ряда `отдельных английских слов`* для получения их базовой формы.

Включается в обработку опцией `use_lemma_infinit = True` в файле `Базовая_директория/Myvocab_58b254sv/settings.txt`.

* Примечание: `отдельные английские слова` - это слова полученные при анализе блока строк в файле .txt,
окруженного строковыми тегами <<word>> и <</word>>.
Допустимо не указывать закрывающий тег <</word>> в конце файла.
Допустимо не поддерживать парность тегов <<word>> и <</word>>. Теги учитываются только при смене их значения.
Пример использования строкового тега <<word>> в анализируемом текстовом файле .txt:
<<word>>

Указанные ниже справочные данные используют только нижний регистр записи текста.
При запуске приложение автоматически приведет все справочники модуля `Infinitive` к нижнему регистру
и сгруппирует их в отсортированном порядке: пользовательские данные, затем данные приложения.

Используемые сокращения:

`ИД`: Идентификатор правила (например, ИД=1010) соответствует номеру операции в программном коде.
`Спр_А`: Справочные данные из файла `irregular_verbs.txt` - неправильные глаголы в трех формах: V1, V2 и V3.
`Спр_Б`: Справочные данные из файла `only_ending_ed.txt` - любые слова, не только глаголы, с `неизменяемым окончанием -ed`.
`Спр_S` Этот справочник из SINGULAR !!! Справочные данные из файла 'only_ending_s.txt' содержат существительные, 
    которые оканчиваются на -s и не допускают изменение этого окончания. 
`Спр_C`: Справочные данные из файла `verbs_ending_non_ed.txt` - глаголы без окончания `-ed`.

Подробную информацию по справочникам смотреть в файле: `3 Справочные данные приложения.txt`

Примечание 1:
При запуске приложения из командной строки с флагом -D:
    python myvocab.py -D
    myvocab.exe -D
отладочные логи, в том числе 'ИД' преобразований, записываются в файл app.log каталога `Базовая_директория/Myvocab_58b254sv`.

Примечание 2:
Все справочники заполнены ограниченным количеством вариантов.
Поэтому по мере работы с программой может возникнуть необходимость в ручном дополнении
этих справочников в том же формате, в каком они уже частично заполнены.


1) Неправильные глаголы в трех формах:

а) Глагол в форме V3 ('ИД'=1010) ('Спр_А'):
    been    -> be


б) Глагол в форме V2 ('ИД'=1020) ('Спр_А')
    was     -> be
    were    -> be


в) Глагол в форме V1 ('ИД'=1030) ('Спр_А')
    be 		-> be
    feed	-> feed


2) Исключить из обработки слова ('ИД'=1040),
которые оканчиваются на -ed, в том числе и глаголы в базовой форме ('Спр_Б'):
    bed 		-> bed
    hundred 	-> hundred
    creed 		-> creed
    speed 		-> speed
    unemployed 	-> unemployed


3) Если глагол оканчивается на -eed или -ed ('ИД'=1050),
то удалить -d, искать слово в справочнике ('Спр_В'):
    braked 		-> brake
    decreed 	-> decree
    freed 		-> free
    moved 		-> move

4) Если глагол оканчивается на -sed ('ИД'=1060),
то удалить -ed, искать слово в справочнике ('Спр_S'):
    stressed 	-> stress
    accessed 	-> accessed
    expressed 	-> express

5) Если глагол оканчивается на -eed или -ed ('ИД'=1070), то удалить -ed, искать слово в справочнике ('Спр_C'):
    willed 		-> will


6) Если глагол оканчивается на удвоенную согласную букву + -ed ('ИД'=1080),
то удалить -ed и убрать одну согласную:
    focussed 	-> focus
    planned 	-> plan
    referred 	-> refer
    travelled 	-> travel


7) Если глагол оканчивается на -ied ('ИД'=1090),
перед которым стоит согласная буква, то удалить -ed и заменить -i на -y:
    copied 		-> copy
    cried 		-> cry
    married 	-> marry
    tidied 		-> tidy


8) Если глагол оканчивается на -xed ('ИД'=1100), то удалить -ed:
    fixed	-> fix
    mixed	-> mix


9) Если глагол оканчивается на -icked или гласная + -acked ('ИД'=1110), то удалить -ked:
    frolicked	-> frolic
    picnicked 	-> picnic
    trafficked 	-> traffic
    bivouacked  -> bivouac


10) Если глагол оканчивается на -ed ('ИД'=1120), то удалить -ed:
    allowed 	-> allow
    labeled 	-> label
    opened 		-> open
    played 		-> play
    walked 		-> walk
    worshiped 	-> worship

11) Составные слова с окончанием -ed обрабатывается для каждого составного слова по вышеприведенным правилам:
    sun-dried       -> sun-dry
    well-known      -> well-know
    meat-fed        -> meat-feed
    wind-powered    -> wind-power
    middle-aged     -> middle-aged
    short-handed    -> short-hand
    strong-willed   -> strong-will

Чтобы исключить из обработки составное слова с окончанием -ed, например, `short-handed`,
необходимо это составное слово добавить в справочник `Спр_Б` (`only_ending_ed.txt`).
