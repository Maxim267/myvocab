Модуль `Casing` (регистр)

На основе использования прописных и строчных символов в исходном тексте, в программе
сформированы правила приведения регистра `отдельных английских слов`* с возможным обращением к справочнику.

Включается в обработку опцией `use_lemma_casing = True` в файле `Базовая_директория/Myvocab_58b254sv/settings.txt`.

* Примечание: `отдельные английские слова` - это слова полученные при анализе блока строк в файле .txt,
окруженного строковыми тегами <<word>> и <</word>>.
Допустимо не указывать закрывающий тег <</word>> в конце файла.
Допустимо не поддерживать парность тегов <<word>> и <</word>>. Теги учитываются только при смене их значения.
Пример использования строкового тега <<word>> в анализируемом текстовом файле .txt:
<<word>>

Указанные ниже справочные данные используют смешанный регистр записи текста.
При запуске приложение не меняет регистр справочников модуля `Casing` (в отличие от `Infinitive` и `Singular`),
и группирует их в отсортированном порядке: пользовательские данные, затем данные приложения.

Используемые сокращения:

'ИД': Идентификатор правила (например, ИД=2010) соответствует номеру операции в программном коде.
`Спр_А`: Справочные данные из файла `mixed_casing.txt` - Формы слов с заданным регистром, в том числе и смешанном.

Примечание 1:
При запуске приложения из командной строки с флагом -D:
    python myvocab.py -D
    myvocab.exe -D
отладочные логи, в том числе 'ИД' преобразований, записываются в файл app.log каталога `Базовая_директория/Myvocab_58b254sv`.

Примечание 2:
Все справочники заполнены ограниченным количеством вариантов.
Поэтому по мере работы с программой может возникнуть необходимость в ручном дополнении
этих справочников в том же формате, в каком они уже частично заполнены.

Примечание 3:
Справочник `Спр_А` рекомендуется пополнять желаемыми вариантами написания слов в требуемом регистре для формируемого vocabulary,
если исходный вариант написания слова в тексте не устраивает. Следует учитывать, что при подключенных модулях `Infinitive` и\или `Singular`,
форма слова может изменяться, например: accorded -> accord, born -> bear, cats -> cat.
Следовательно, в таких случаях нужный регистр необходимо применять уже к преобразованным словам: Accord, BeAr, CAT.

Примечание 4:
Если включена опция `use_lemma_casing`, приложение применяет декапитализацию первых слов предложения,
при которой слово пишется со строчной буквы вместо прописной,
при условии наличия в тексте файла соответствующей формы в нижнем регистре.

Примечание 5:
Справочник 'Спр_А' содержит список слов с заданным регистром. Например, если добавить в справочник
форму `he` (в нижнем регистре), то все варианты этого слова из анализируемого текста (`He`, `hE`, `HE`) (независимо от регистра)
будут преобразованы в заданный `he` (в нижнем регистре).
Справочник может содержать несколько форм для одного заданного слова.
Например, `March` и `march`, занесенные в справочник 'Спр_А', задают только два варианта преобразования формы для соответствующих слов.
И тогда каждое слово в тексте, как-то: `MARCH`, `march` и `mArCh`, преобразуется только в один из двух возможных вариантов:
`MARCH` -> `March`, `march` -> `march` и `mArCh` -> `march`, на основе встроенного алгоритма (учитывающего вес символов и их регистр).

Примечание 6:
Преобразование регистра слова в модуле `Casing` производится после его обработки в подключенных модулях: `Infinitive` или `Singular`.
Например, слово `ACCORDED` преобразуется сначала в модуле `Infinitive` как: accorded -> accord.
И только затем происходит смена регистра: ACCORD -> Accord, при условии, что в справочник `Спр_А` занесена форма `Accord` (не Accorded !!!).
Однако в тех случаях, когда слово из текста полностью совпадает со словом из справочника `Спр_А` (включая точное совпадение по регистру),
данное слово исключается из обработки любым модулем и сохраняется в исходном виде.

Примечание 7:
Если включена опция `use_word_translate`, перевод слов с английского языка на выбранное направление
осуществляется после обработки в подключенных модулях: `Infinitive` и\или `Singular` и\или `Casing`.

1) Если анализируемое слово отсутствует в справочнике 'Спр_А' ('ИД'=2020) без учета регистра,
оно первоначально обрабатывается подключенными модулями `Infinitive` или `Singular`,
после чего слово приводится к исходному виду по встроенному алгоритму (с учетом длины слова, а также совпадения символов и регистра):
    ACCorded -> accord -> ACCord

Вероятно, если анализируемое слово является именем собственным, например, `Arsenius`, и если опция `use_lemma_casing` включена постоянно,
достаточно занести в справочник 'Спр_А' модуля `Casing` (файл `mixed_casing.txt`) слово `Arsenius`.
Иначе необходимо занести `arsenius` в справочник модуля `Singular` (файл `only_ending_s.txt`), для предотвращения отсечения окончания -s,
после чего слово приводится к исходному виду по встроенному алгоритму:
    Arsenius -> Arsenius

2) Если анализируемое слово присутствует в справочнике 'Спр_А' ('ИД'=2020) без учета его регистра,
то это слово сразу приводится к заданному виду по встроенному алгоритму (с учетом длины слова, а также совпадения символов и регистра):
    ACCord -> Accord

Если анализируемое слово находится в начале предложения, оно пишется с прописной (заглавной) буквы, даже если оно не относится к именам собственным.
Встроенный алгоритм может автоматически сменить регистр первой буквы у части таких слов на нижний (см. описание выше в примечании).
Если есть необходимость декапитализации слов, которые не затронул этот алгоритм, их необходимо занести в справочник 'Спр_А' модуля `Casing` в заданном регистре.

3) Если анализируемое слово присутствует в справочнике 'Спр_А' ('ИД'=2010) c учетом его регистра,
то исходный вид этого слова сохраняется:
    ACCord -> ACCord

4) Если анализируемое слово присутствует в справочнике 'Спр_А' ('ИД'=2020) в нескольких вариантах написания без учета регистра,
первоначально происходит выбор приоритетного варианта на основе встроенного алгоритма (учитывающего вес символов и их регистр).
Затем этот вариант приводится к исходному виду по встроенному алгоритму (с учетом длины слова, а также совпадения символов и регистра):
    ACCord -> ACCORD

5) Дефисные сложные слова анализируются на уровне каждого составляющего их элемента в соответствии с вышеприведенными правилами
(например, элемент `born` может преобразоваться в `bear`, если подключен модуль `Infinitive`):
    MARCH-born -> March-bear

Для того чтобы исключить из обработки дефисные сложные слова, например, `MARCH-born`,
необходимо внести это сложное слово в справочник `Спр_А`, с заданным регистром букв (например, `March-born`):
    MARCH-born -> March-born
