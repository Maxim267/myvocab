`myvocab` - это приложение командной строки.
В результате работы приложения создается каталог `Myvocab_58b254sv` в директории пользователя `Документы`:
    📁 Документы/
        📁 Myvocab_58b254sv/

Все выполненные преобразования слов, при каждом запуске программы,
автоматически сохраняются в перезаписываемом файле `parsed_pairs.txt`:
    📁 Документы/
        📁 Myvocab_58b254sv/
            📁 Infinitive/
                📁 out/
                    📄 parsed_pairs.txt
            📁 Singularization/
                📁 out/
                    📄 parsed_pairs.txt
            📁 Casing/
                📁 out/
                    📄 parsed_pairs.txt

Infinitive - преобразования связанные с изменением окончания -ed в базовую форму глаголов;
Singularization - преобразования связанные с изменением окончания -s в форму единственного числа;
Casing - преобразования связанные с изменением регистра слов;

Пользователю предоставляется возможность самостоятельно проверить корректность этих преобразований.

Часть преобразований, которые являются корректными,
пользователю необходимо скопировать в дозаписываемый файл `reviewed_pairs.txt`:
    📁 Документы/
        📁 Myvocab_58b254sv/
            📁 Infinitive/
                📁 in/
                    📄 reviewed_pairs.txt
            📁 Singularization/
                📁 in/
                    📄 reviewed_pairs.txt
            📁 Casing/
                📁 in/
                    📄 reviewed_pairs.txt

При следующем запуске программа автоматически сравнит перезаписываемый файл `parsed_pairs.txt`
с существующим файлом `reviewed_pairs.txt` и запишет результат сравнения в перезаписываемый файл `unreviewed_pairs.txt`:
    📁 Документы/
        📁 Myvocab_58b254sv/
            📁 Infinitive/
                📁 out/
                    📄 unreviewed_pairs.txt
            📁 Singularization/
                📁 out/
                    📄 unreviewed_pairs.txt
            📁 Casing/
                📁 out/
                    📄 unreviewed_pairs.txt

При последующих запусках приложения пользователю удобнее проверять корректность преобразований в файлах:
    `out/unreviewed_pairs.txt`
так как в них отсутствует информация по уже проверенным преобразованиям.


Часть преобразований слов, которые являются некорректными, необходимо исправлять внесением изменений в справочные данные:
    📁 Myvocab_58b254sv/
        📁 Infinitive/
            📁 in/
                📄 irregular_verbs.txt
                📄 only_ending_ed.txt
                📄 verbs_ending_e.txt
                📄 verbs_ending_non_ed.txt
        📁 Singularization/
            📁 in/
                📄 irregular_plural_nouns.txt
                📄 only_ending_s.txt
                📄 singular_ending_non_s.txt
        📁 Casing/
            📁 in/
                📄 mixed_casing.txt
Изменять справочные данные рекомендуется только после получения результата преобразования слов и необходимости его корректировки.

При обновлении справочных данных рекомендуется обновлять одноименные справочные данные и в проекте:
    📁 myvocab/
        📁 src/
            📁 myvocab/
                📁 parsing/
                    📁 infinitive/
                        📁 data/
                            📄 irregular_verbs.txt
                            📄 only_ending_ed.txt
                            📄 verbs_ending_e.txt
                            📄 verbs_ending_non_ed.txt
                    📁 singularization/
                        📁 data/
                            📄 irregular_plural_nouns.txt
                            📄 only_ending_s.txt
                            📄 singular_ending_non_s.txt
                    📁 Casing/
                        📁 data/
                            📄 mixed_casing.txt

Только после удаления каталога `Документы/Myvocab_58b254sv` и нового запуска приложения,
справочные данные проекта будут скопированы во вновь созданный каталог `Документы/Myvocab_58b254sv`.
При обновлении справочных данных и запуске приложения из myvocab.exe, необходимо пересоздать файл myvocab.exe.


ПРИМЕРЫ исправления некорректных преобразований слов:

-------------------------------------------------------------------------------
Infinitive:
-------------------------------------------------------------------------------

1. Преобразование неправильного глагола striven (V3) отсутствует
или некорректное преобразование неправильного глагола strived (V3) правилом `отбрасывания окончание -ed`

strive - strive
strived - striv

Необходимо добавить неправильный глагол в трех формах в справочник `irregular_verbs.txt`,
если несколько вариантов для (V2) или (v3), то они разделяются `/`:

	strive strove/strived striven/strived

2. Некорректное применение правила ('ИД': 1110) в преобразованиях: `отбросить окончание -ked`
для глаголов, у которых базовая форма не имеет окончание `-ed`:

pricked - pric

Необходимо заполнить справочник `verbs_ending_non_ed.txt` базовыми формами этих глаголов,
чтобы предотвратить их от применения правила `отбросить окончание -ked`:

prick

3. Некорректное применение правила ('ИД': 1120) в преобразованиях: `отбросить окончание -ed`
для глаголов, у которых базовая форма имеет окончание `-e`:

muted - mut
optimized - optimiz

Необходимо заполнить справочник `verbs_ending_e.txt` базовыми формами этих глаголов,
чтобы предотвратить их от применения правила `отбросить окончание -ed`:

mute
optimize

4. Некорректное применение правила ('ИД': 1120) в преобразованиях: `отбросить окончание -ed`
для глаголов, у которых базовая форма имеет окончание `-ed`:

unexpected - unexpect
unrelated - unrelat

Необходимо заполнить справочник `only_ending_ed.txt` базовыми формами этих глаголов,
чтобы предотвратить их от применения правила `отбросить окончание -ed`:

unexpected
unrelated

5. Некорректное применение правила ('ИД': 1080) в преобразованиях: `2-х согласных + ed`
для глаголов, у которых базовая форма не имеет окончание `-ed` или `-e`:

called - cal
spelled - spel

Необходимо заполнить справочник `verbs_ending_non_ed.txt` базовыми формами этих глаголов,
чтобы предотвратить их от применения правила `2-х согласных + ed`:

call
spell

6. Некорректное применение правила ('ИД': 1080) в преобразованиях: `2-х согласных + ed`
для глаголов, у которых базовая форма имеет окончание `-ss`:

stressed - stres
expressed - expres

Необходимо заполнить Singular - справочник `only_ending_s.txt` базовыми формами этих глаголов (существительных),
чтобы предотвратить их от применения правила `2-х согласных + ed`:

stress
express

-------------------------------------------------------------------------------
Singularization:
-------------------------------------------------------------------------------

1. Некорректное применение правила ('ИД': 70) в преобразованиях: `заменить -ves на -f`
для слов, у которых базовая форма имеет окончание `-ve`:

adjectives -> adjectif
perspectives -> perspectif
drives - drif
involves - involf

Необходимо заполнить справочник `singular_ending_non_s.txt` базовыми формами этих слов,
чтобы предотвратить их от применения правила `заменить -ves на -f`:

adjective
perspective
drive
involve

2. Некорректное применение правила ('ИД': 140) в преобразовании: `отбросить окончание -es`
для слов, у которых базовая форма имеет окончание `-e`:

uses - us

Необходимо заполнить справочник `singular_ending_non_s.txt` базовыми формами этих слов,
чтобы предотвратить их от применения правила `отбросить окончание -es`:

use

2. Некорректное применение правила ('ИД': 160) в преобразовании: `отбросить окончание -es`
для слов, у которых базовая форма не имеет окончание `-s`:

houses - hous
cases - cas
clauses -> claus
tenses - tens

Необходимо заполнить справочник `singular_ending_non_s.txt` базовыми формами этих слов,
чтобы предотвратить их от применения правила `отбросить окончание -es`:

house
case
clause
tense

3. Некорректное применение правила ('ИД': 180) в преобразовании: `отбросить окончание -s`
для слов с `неизменяемым окончанием -s`:

as - a
confucius - confuciu
stateless - stateles

Необходимо заполнить справочник `only_ending_s.txt` этими словами,
чтобы предотвратить их от применения правила `отбросить окончание -s`:

as
confucius
stateless

4. Некорректное применение правила ('ИД': 180) в преобразовании: `отбросить окончание -s`
для слов, у которых базовая форма не имеет окончание `-es`

does - doe
goes - goe

Необходимо заполнить справочник `singular_ending_non_s.txt` этими словами,
чтобы предотвратить их от применения правила `отбросить окончание -s`:

do
go

-------------------------------------------------------------------------------
Casing:
-------------------------------------------------------------------------------

1. Слово сформировано в нежелательном регистре ('ИД': 2010) или ('ИД': 2020):
    File
    THE
    MARCH
    mARch
    monday
Необходимо пополнить/изменить справочник `mixed_casing.txt` вариантами написания слов в требуемом регистре:
    file
    the
    March
    march
    Monday
