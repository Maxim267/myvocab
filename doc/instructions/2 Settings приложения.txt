`myvocab` - это приложение командной строки.
При запуске приложение запрашивает у пользователя базовый каталог 
для анализа (парсинга) текстовых файлов. В результате работы приложения 
в выбранной базовой директории создается каталог `Myvocab_58b254sv` со сформированными данными:

    📁 Базовая_директория/
        📁 Myvocab_58b254sv/
            📄 settings.txt
            📄 supported_target_languages.txt
            📄 app.log
            📄 directories.txt
            📄 view_all_used_paths.txt
            📄 vocabulary.txt

`vocabulary.txt` - Файл со сформированным vocabulary.

`settings.txt` - Файл настроек приложения.
Это единственный файл в базовом каталоге, доступный пользователю для редактирования и обмена данными с приложением.
При удалении каталога `базовый_каталог\Myvocab_58b254sv` все изменения в `settings.txt` будут утеряны.
Новый запуск приложения создаст этот каталог и заполнит `settings.txt` данными проекта.

`supported_target_languages.txt` - Файл со списком поддерживаемых целевых языков (код: название).
Подробная информация по данному файлу приводится ниже.

`app.log` - Файл логов с уровнем INFO.
При запуске приложения из командной строки с флагом -D:
    python myvocab.py -D
    myvocab.exe -D
в файл `app.log` записываются отладочные логи уровня DEBUG, в том числе все изменения слов c идентификаторами правила `ИД`.
Также в этом же режиме в папку `Translate` записываются все слова отправленные на перевод и полученный перевод:
    📁 Базовая_директория/
        📁 Myvocab_58b254sv/
            📁 Translate/

`directories.txt` - Файл с древовидной структурой каталогов парсинга текстовых фалов, начиная с базового каталога.
`view_all_used_paths.txt` - Файл со списком всех используемых в приложении директорий.

Также одноименный каталог `Myvocab_58b254sv` создается в директории пользователя `Документы`:
    📁 Документы/
        📁 Myvocab_58b254sv/
Файлы в директории `Документы\Myvocab_58b254sv` используются как справочные данные при изменении формы слов.
Подробную информацию по справочным данным смотреть в файле:
    3 Справочные данные приложения.txt


Первый запуск приложения заполняет файл настроек settings.txt данными по умолчанию:

--------------------------------------------------
Содержимое файла settings.txt:
--------------------------------------------------
result_file = vocabulary.txt
directories_file = directories.txt
use_lemma_singular = True
use_lemma_infinit = True
use_word_translate = False
target_language_code = ru
use_order_text = True
use_dir_with_leading_exclamation_mark = False
------------------------------------------------

result_file - Наименование формируемого файла vocabulary.
directories_file - Наименование файла содержащего древовидную структуру парсинга каталогов начиная с базового.
use_lemma_singular - Флаг изменения множественной формы `отдельных английских слов`* в форму единственного числа.
use_lemma_infinit - Флаг изменения формы прошедшего времени `отдельных английских глаголов` в базовую форму.
use_word_translate - Флаг перевода `отдельных английских слов` на выбранное направление (target_language_code).
target_language_code - Направление перевода `отдельных английских слов` (всегда с английского).
use_order_text - Флаг сортировки текста в формируемом файле vocabulary.
use_dir_with_leading_exclamation_mark - Флаг использования в парсинге папок и файлов, имя которых начинается с "!".


* Примечание: `отдельные английские слова` - это слова полученные при анализе блока строк в файле .txt,
окруженного строковыми тегами <<word>> и <</word>>.
Допустимо не указывать закрывающий тег <</word>> в конце файла.
Допустимо не поддерживать парность тегов <<word>> и <</word>>. Теги учитываются только при смене их значения.
Пример использования строкового тега <<word>> в анализируемом текстовом файле .txt:
<<word>>


Примечание: При вводе некорректного значения любой опции настроек выводится сообщение:
    WARNING - Invalid processing option 'имя опции'
и опция принимает значение по умолчанию.
Допустимо при редактировании вместо True или False использовать соответственно 1 или 0.

Примечание:
`target_language_code` по умолчанию равен `ru`.
После первого запуска программы автоматически формируется файл:
    `supported_target_languages.txt`
со списком поддерживаемых целевых языков (код: название), код которых допустимо использовать
для значения опции `target_language_code`. Если заданное значение `target_language_code` отсутствует
в файле `supported_target_languages.txt`, то этот файл автоматически обновится,
и если заданное значение повторно не обнаружится в файле, опция примет значение по умолчанию: `ru`
и флаг `use_word_translate` выключится.
При выставленной опции 'use_word_translate' выведется сообщение, например:
    INFO - Translation direction: `English` to `русский` (`en` -> `ru`)

Примечание:
Если `use_order_text` равен True, то сортировка и уникальность применяется ко всему формируемому `vocabulary`.
Если `use_order_text` равен False, то уникальность применяется к каждому файлу отдельно
в рамках формируемого `vocabulary`, с включением имен этих файлов.
Сортировка слов соответствует порядку слов в файле с учетом сохранения уникальности.
